# Task Manager CLI

A command-line task management application written in Python.

## Purpose

This project is being developed to learn software engineering concepts through practice.

The project will cover:

- Python project structure
- Git and GitHub
- Command-line applications
- Functions and modules
- File-based data storage
- Error handling
- Unit testing
- Refactoring
- Documentation

## Planned Features

- Add a task
- List tasks
- Mark a task as completed
- Delete a task
- Save tasks locally
- Load tasks when the application starts

## Technologies

- Python 3.14
- Git
- GitHub
- VS Code
- Codex
- Pytest
