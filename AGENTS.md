# AGENTS.md

## Project Context

This project is being developed by a Computer Engineering student who is learning software engineering.

The goal is not only to build a working application, but also to understand the reasoning behind the implementation.

## Development Rules

When making significant changes:

1. Explain what needs to be changed.
2. Explain why the change is necessary.
3. Prefer simple and readable solutions.
4. Avoid unnecessary abstractions.
5. Do not modify unrelated files.
6. Do not delete files unless necessary.
7. Explain new libraries before adding them.
8. Keep functions small and focused.
9. Use meaningful names for variables and functions.
10. Run relevant tests after changes.

## Learning Mode

For important concepts:

- Explain the concept before implementation.
- Mention reasonable alternatives when relevant.
- Explain important architectural decisions.
- Do not hide complexity without explanation.
- Encourage the developer to implement small parts manually.

## Git

Do not create commits unless explicitly requested.

Before major changes, inspect the current Git status.

## Testing

Important application logic should have automated tests.

Tests should be simple, readable, and independent.
